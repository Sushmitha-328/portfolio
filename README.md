# Sushmitha Lavanuru — Developer Portfolio

A modern, dark-themed portfolio built with **React + Vite**, featuring Framer Motion animations, a 3D Three.js neural background, custom interactive project simulations, and a fully responsive corporate design system.

---

## 🚀 Tech Stack

| Layer        | Technology                                       |
| ------------ | ------------------------------------------------ |
| Framework    | React 18                                         |
| Build Tool   | Vite 6                                           |
| Animations   | Framer Motion 11                                 |
| 3D Graphics  | Three.js                                         |
| Styling      | Modern Glassmorphic CSS (Plus Jakarta Sans, Inter, DM Mono) |
| Icons        | React Icons                                      |
| Contact Form | EmailJS                                          |
| Deployment   | Vercel                                           |

---

## 📦 Setup & Local Development

```bash
# 1. Clone the repository
git clone https://github.com/Sushmitha-328/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start the local development server
npm run dev
```

---

## 🏗️ Production Build

```bash
# Build the production bundle
npm run build

# Preview production build locally
npm run preview
```

The output will be generated in the `dist/` directory.

---

## 🌐 Deploy to Vercel

1. Push this repository to GitHub: `https://github.com/Sushmitha-328/portfolio`.
2. Head to [Vercel](https://vercel.com) and import the repository.
3. Vercel automatically detects the Vite framework.
4. Click **Deploy**. The included `vercel.json` ensures full SPA client-side routing.
